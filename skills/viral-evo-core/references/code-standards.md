# 代码产出规范（全员强制，pipeline-engineer 守门）

## 结构
- 模块化函数：单一职责，函数间低耦合
- 禁硬编码：路径/参数全部走配置文件或函数参数
- 禁全局污染：不用全局变量传状态
- Notebook 细胞顺序：质控 → 主流程 → 校验 → 导出

## 注释
- 全中文注释：每个参数写含义 + 可调空间
- 文件头注释块：用途 / 输入 / 输出 / 依赖安装命令（conda/pip）/ 运行示例 / 日志位置

## 健壮性
- try/except 强错误处理，报错信息指出原因与对策
- 关键步骤日志：时间戳 + 进度百分比
- 禁静默运行：无日志无进度 = 返工

## 可复现
- 附依赖安装命令与版本
- 随机过程固定种子
- 输出文件带日期戳

## 极简与诚实（Karpathy 准则内化）
- 外科手术式修改：只动该动的，不顺手重构
- 实现前先声明假设与可验证的成功标准
- 能标准库不引新依赖；能简单不过度设计
- 报错不猜，先读错误原文再修
