# 代码产出规范（全员强制，pipeline-engineer 守门）

## 结构
- 模块化函数：单一职责，函数间低耦合
- 禁硬编码：路径/参数全部走配置文件或函数参数
- 禁全局污染：不用全局变量传状态
- Notebook 细胞顺序：质控 → 主流程 → 校验 → 导出

## 注释
- 全中文注释：每个参数写含义 + 可调空间
- 文件头注释块：用途 / 输入 / 输出 / 依赖安装命令（conda/pip）/ 运行示例 / 日志位置

## 健壮性
- try/except 强错误处理，报错信息指出原因与对策
- 关键步骤日志：时间戳 + 进度百分比
- 禁静默运行：无日志无进度 = 返工

## 可复现
- 附依赖安装命令与版本
- 随机过程固定种子
- 输出文件带日期戳

## 极简与诚实（Karpathy 准则内化）
- 外科手术式修改：只动该动的，不顺手重构
- 实现前先声明假设与可验证的成功标准
- 能标准库不引新依赖；能简单不过度设计
- 报错不猜，先读错误原文再修

## 图产出纪律（2026-10-14 治理约束融入）

1. **一图对应一个 ipynb**：每张正式图必须有其专属 notebook（图名与 notebook 同名，如 `Fig4_x.ipynb` ↔ `Fig4_x.pdf`）。图的任何更新必须**先修改 notebook 代码、再基于修改后代码重跑产图**——禁止直接改图文件、禁止"先出图后补代码"。
2. **输出格式**：正式图输出为 **pdf**（矢量，`savefig('*.pdf')`，300 DPI）；PNG 仅作预览副本，不作为定稿。
3. **路径显式声明**：notebook 首个 cell 配置区集中声明原始数据输入路径与图输出路径（绝对路径或项目根相对路径），图注/产出摘要中复述——禁止散落硬编码、禁止输出路径隐含。
4. **非必要不新建**：更新已有图时优先在其既有 notebook 上修改；仅当图本身是新产出时才允许新建 notebook+图 2 个文件，禁止连带新建中间文件。

## 文件治理与索引同步（2026-10-14 治理约束融入）

1. **旧文件优先**：修改需求优先在既有文件上外科手术式更新（v 前缀升级），禁止为规避合并冲突而另起同名新篇。
2. **冗余清理**：每次落盘任务顺带检查同目录 `.bak`/`.tmp`/重复 CSV/孤儿输出（无任何 notebook 引用），列入清理清单交 archivist 执行删除（删除须红色警告+二次确认）。
3. **CLAUDE.md 索引同步**：任何文件的新建/删除/改名/目录调整，同一任务内必须同步更新对应 CLAUDE.md 的文件夹索引（04_H5 侧为 §G 模块链；专家包侧为团队级 CLAUDE.md）——索引与磁盘不一致 = 任务未完成。
