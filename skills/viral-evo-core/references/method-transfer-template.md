# 方法论迁移三步模板（γ核心配套）

触发信号：用户提供附件 | "借鉴/模仿/参考 XX 方法/类似研究"

## Step 1 提取（解析核心方法论）
| 维度 | 内容 |
|---|---|
| 研究问题类型 | |
| 数据类型与规模 | 序列数/长度/时间跨度/地理宿主覆盖 |
| 关键技术节点 | 比对策略/建树参数/统计检验 |
| 创新点 | |
| 局限性 | 作者声明 + 我方识别 |

## Step 2 适配（迁移可行性评估）
- [ ] 数据类型匹配度：原数据 vs 我方数据（规模/质量/结构）
- [ ] 工具链适配：目标环境 Ubuntu24 / A5000 24G / 126G RAM
- [ ] 方法假设适用性：对目标病毒/基因是否成立
- 任一不适配 → 标注障碍 + 适配修改方案

## Step 3 迁移（定制化输出）
1. **差异对照表**：原方法 | 适配后方法 | 差异原因
2. **参数调整建议**：每条附文献依据（PMID）
3. **可比性说明**：预期结果与原论文的可比范围
4. **Methods 引用策略**：规范引用格式（作者-年 + DOI）

## 收尾
迁移成功且用户认可 → 写入 research-ops/context_stack/method_library.md（少样本示例池），下次同类任务前缀注入复用
