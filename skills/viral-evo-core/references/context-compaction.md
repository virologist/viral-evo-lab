# 上下文压缩协议（Context Compaction）
> P1-6 2026-09-18 建档。借鉴 Anthropic Managed Agents（2026-04）+ LangGraph compaction reducer + LlamaIndex CompactionEvent。
> 目标：防 context rot——把"事件日志"与"模型上下文"分离，只把决策相关的最小切片放进 prompt。

## 一、核心原则

| 原则 | 说明 |
|---|---|
| 分离日志与上下文 | 原始工具输出/长文本落盘（research-ops/），prompt 里只放**引用 ID + 结论摘要** |
| 稳定前缀缓存 | 静态内容（角色定义/门控阈值/约束）放 prompt 前部；动态内容（本轮数据）放后部 |
| 里程碑后修剪 | 每完成一个 Phase，将其长轨迹替换为**已核验的短摘要** |
| 摘要四问 | 摘要必须回答：**变了什么 / 什么仍成立 / 什么被阻塞 / 什么证据支持** |
| 冲突显式保留 | 新事实与旧事实冲突时**记录冲突**，不静默替换 |

## 二、触发阈值（本项目落地值）

| 触发条件 | 动作 | 执行人 |
|---|---|---|
| 单轮 context 用量 > 85% | 触发压缩：清旧工具结果，保留结论+指针 | 主理人 |
| 单个 JSON 文件条目 > 15 条 | 语义摘要压缩，保留核心锚点；bump schema_version | archivist |
| 简报类输出（WF3）单次 > 500 行 | 落盘全文 + prompt 内只留 ≤200 字摘要 | archivist |
| 同主题 RAW 数据 > 3 份 | 合并为一份"当前真相"文档 + 归档旧版 | archivist |

## 三、压缩执行步骤

1. **识别**：本轮哪些内容属于"事件日志"（工具原始输出、长表格、中间计算）？
2. **落盘**：日志写入 `research-ops/30_results/` 或 `01_diagnostics/`，记路径
3. **摘要**：按四问写 ≤200 字摘要（变了什么/仍成立/被阻塞/证据）
4. **替换**：prompt 内用 `[已压缩→路径:xxx | 摘要:...]` 替换原文
5. **一致性**：确认 JSON 真源与 .md 视图未漂移（archivist 执行）

## 四、禁止事项

- ❌ 删除未落盘的上下文（压缩前必须先落盘）
- ❌ 压缩"可证伪条件"与"质量门控阈值"（属决策关键，永远保留原文）
- ❌ 静默替换冲突事实（必须记录冲突）
- ❌ 在未完成 Phase 时压缩该 Phase 的中间状态（会丢工作）

## 五、失败模式（压缩机制防的问题）

| 失败模式 | 表现 | 压缩机制的防护 |
|---|---|---|
| Context rot | 长会话后关键约束被挤出窗口，行为漂移 | 阈值触发 + 关键内容永久保留清单 |
| 过早胜利 | 看到局部进展就宣布完成 | 摘要四问强制回答"什么仍被阻塞" |
| 状态丢失 | 换 session 后不知做到哪 | 落盘 + Changelog（claude-progress.txt 模式） |
| 写放大 | 每轮全量重写 | 增量写入 + 纯检索轮零写 |
