# 检索源优先级与通道（4R 检索模块配套）

## 触发条件
数据库版本 | 工具最新参数 | 文献支撑需求 | 方法前沿性验证 | 时效性词（最新/前沿/2024-2026）| 附件内容补充

## 期刊优先级（病毒演化方法）
1. Nature Methods、Cell Host & Microbe
2. Virus Evolution、PLoS Pathogens
3. Bioinformatics、Nucleic Acids Research
4. Nat Ecol Evol、Science/Nature/Cell（机制级突破）

## 数据库
| 库 | 用途 |
|---|---|
| GISAID | 流感时序/地理/宿主元数据 |
| NCBI GenBank | 序列注释、非流感病毒 |
| UniProt | 蛋白功能注释 |
| bioRxiv/medRxiv | 预印本预警（未过同行评审，标注使用） |
| IEDB | 免疫表位 |
| PDB | 实验结构 |

## 检索通道（按可用性降级）
1. MCP：PubMed / arxiv / bioRxiv / Crossref / BioMCP（DOI-PMID 核验必走 Crossref 或 PubMed）
2. WebSearch / WebFetch 降级
3. 每次检索记录：通道 | 查询词 | 日期 | 命中数

## 置信度标注体系
- [高置信|PMID:xxx] — 原文已核验
- [中等置信|局限:xxx] — 元数据核验，全文未读
- [推断|待核查→方向] — 无直接来源的逻辑推断

## 冲突处理
发现冲突文献 → 证据对比表（文献|样本量|方法|结论|弱点攻击）→ 攻击弱方（样本小/逻辑漏/方法旧）→ 给推荐立场
