## 五、残余风险

1. **JSON-MD 双轨漂移** — 已设"每轮 diff + JSON 优先"协议，但依赖 archivist 执行纪律；若跳过则回到双源问题
2. **stable prefix 实际收益未实测** — prompt cache 是否被 WorkBuddy 平台启用未知，30-50% 节省为 [INFERRED]
3. **修复路由循环** — 复杂缺陷可能反复往返；已用 ≤5 全局预算兜底，但预算耗尽后的"残余缺陷报告"依赖用户裁决
4. **maxTurns 静态限制** — 粒度控制是等效方案而非真正动态；极端长任务（如全基因组 8 节段批量重建）仍可能撞 50 轮上限
